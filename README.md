# The Trolley Problem - Philosophical Game

A lo-fi 16-bit style interactive game exploring classic ethical dilemmas.

## Project Structure

```
TrolleyProblem/
├── index.html        # Standalone version (all-in-one HTML file)
├── v1/               # Version 1: Basic 5-scenario game
│   ├── index.html    # HTML structure (for CodePen HTML panel)
│   ├── style.css     # Styles (for CodePen CSS panel)
│   └── script.js     # Game logic (for CodePen JS panel)
└── v2/               # Version 2: Comprehensive 12-scenario game
    ├── index.html    # HTML structure (for CodePen HTML panel)
    ├── style.css     # Styles (for CodePen CSS panel)
    └── script.js     # Game logic (for CodePen JS panel)
```

## Testing on CodePen

### Option 1: Quick Test (Standalone)
Open `index.html` directly in a browser - it contains everything in one file.

### Option 2: CodePen Testing

1. Go to [codepen.io](https://codepen.io) and create a new pen
2. Choose a version (`v1/` for basic, `v2/` for comprehensive)
3. Copy the contents of each file into the corresponding panel:
   - `index.html` → HTML panel
   - `style.css` → CSS panel
   - `script.js` → JS panel

## Versions

### v1 - Basic Version (5 Scenarios)
- The Classic Trolley Problem
- The Fat Man
- The Loop
- The Transplant
- The Sacrifice

### v2 - Comprehensive Version (12 Scenarios)
Includes all v1 scenarios plus:
- The Loved One (partiality)
- The Ticking Bomb (torture)
- The Deathbed Promise
- The Child's Life (age-based)
- The Murderer at the Door
- The Ones Who Walk Away (Omelas)
- The Guilty One
- The Convergence (ultimate test)

Features philosophical scoring, consistency tracking, and alignment with famous philosophers.
